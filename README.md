# TEL_AI_AGENT
AI AGENT TELEGRAM BOT
یک دستیار هوش مصنوعی مبتنی بر LLM که از طریق تلگرام به سوالات کاربران پاسخ می‌دهد.

## ✨ ویژگی‌ها
- پاسخ‌گویی هوشمند با مدل زبانی LLaMA 3.3 70B
- حفظ تاریخچه مکالمه برای پاسخ‌های منسجم‌تر
- اجرای سریع با Groq API
- دیپلوی خودکار با GitHub Actions

## 🛠️ تکنولوژی‌ها
- Python
- python-telegram-bot
- Groq API (LLaMA 3.3 70B)
- GitHub Actions (CI/CD)

## 🚀 نحوه اجرا
1. کلون کردن ریپازیتوری
2. تنظیم متغیرهای محیطی:
   - `TELEGRAM_TOKEN`
   - `GROQ_API_KEY`
3. نصب پکیج‌ها: `pip install -r requirements.txt`
4. اجرا: `python bot.py`
